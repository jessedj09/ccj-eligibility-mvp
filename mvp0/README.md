# mvp0/ 는 더 이상 사용되지 않는 초기 스냅샷입니다

이 폴더는 MVP0 최초 검증 단계에서 만든 `rule_engine.py`/`notices_data.py`/`profiles_data.py`의
초기 버전이다. **어떤 테스트나 `app.py`도 이 폴더를 import하지 않는다** — 실행 기준은 항상
`src/`이며, 이 폴더는 초기 설계 흔적을 남겨두기 위한 참고용 스냅샷일 뿐이다.

실행·수정·테스트는 전부 `src/` + `tests/`를 기준으로 한다. 이 폴더의 코드는 MVP0.1
개정(재학요건·연령/사회초년생·혼인기간/자녀요건·자녀가산 등)을 반영하지 않은 옛 버전이므로
참고 목적 외에는 사용하지 말 것.
