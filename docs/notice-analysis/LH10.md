## 7. 모호하거나 해석이 갈리는 지점 (MANUAL_REVIEW 후보)

1. **2·3순위 미모집의 판정 코드**: 서울·연접지역 밖 거주자이면서 재학 대학도 해당 지역 밖인 대학생은 신청 대상이 아님(p.6 "2,3순위 이번 공고에서는 모집하지 않음"). 이를 INELIGIBLE로 볼지, 별도 사유 코드로 볼지 결정 필요. 거주지·재학지 정보가 없으면 NEEDS_INFO.
2. **미성년 대학생 신청 가능 여부**: p.3 성년자 예외에 대학생이 없음(N3와 다름). 자격 요건 차이인지 문구 누락인지 불확실.
3. **고령자 가산표의 '출생자녀'**: 고령자 세대에 ’23.3.28 이후 출산 자녀(입양·태아 포함)가 있는 경우를 상정한 표(p.7) — 1인 가구 행에는 자녀 있는 조합이 없음 → 입력 모순 처리(NO_ROW).
4. **고령자 '65세 이상'의 주체**: p.7 "65세 이상인 자" = 신청자 본인으로 읽힘. 배우자만 65세 이상인 경우는 원문 근거 없음.
5. **고령자 소득에 맞벌이 구분 없음**: 맞벌이 부부 가산이 없음(p.7) — 원문대로 단일 기준.

## 8. 같은 그룹 내 비교

- LH08(신혼·한부모만), LH09(지역전략+대학생·청년)와 계층 구성이 다름. 회차만 다른 공고 아님.
- 대학생 수치·가산표는 N3·LH09와 동일. 고령자 자산 기준(345M/가산 379M·413M)은 신혼·한부모·지역전략과 같은 금액대.
- 2세 미만 자녀 30% 우선배정 문구: LH10 있음, LH08·LH09 없음.
- '판단기준일 중 금융자산·부채는 조사기준일' 문구: LH10(p.1, p.9)·LH09(p.14)에 있음, LH08에는 없음.
- 텍스트 추출 문제: p.2 공급형별 면적 표가 열 단위로 분해되어 세로 나열됨(자격과 무관). p.2→p.3 문장 분단("전용면적 36㎡이상 / 주택형의 예비자"). p.4~5에서 "예비입주자 중복선정" 문장이 3-1 대학생 본문 사이로 끼어듦(243→278행). p.5 출산자녀 정의 자간 벌어짐. p.13~14 제출서류 표와 당첨발표 절 순서가 섞임. 자격 수치는 모두 판독 가능.
