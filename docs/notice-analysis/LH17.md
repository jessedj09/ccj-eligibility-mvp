## 6. 순위·배점·우선공급 구조 (범위 밖 요약)
- 일반공급 순위(p.7, p.9): 1순위 = 본인 또는 배우자의 거주지나 소득 근거지가 의왕시 또는 연접지역(과천·안양·군포·안산·수원·성남·용인) / 2순위 = 1순위 이외의 경기도·서울특별시·인천광역시 / 3순위 = 나머지.
- 우선공급 배점(p.8): ① 의왕시 3년 이상 3점·3년 미만 1점 ② 청약 24회 이상 3점·6~23회 1점.
- 경쟁 시(p.8): 우선 = 2세 미만 자녀 → **배점** → 의왕시 거주기간 → 추첨 (LH14와 달리 '순위' 단계 없음) / 일반 = 순위 → 추첨.
- 주거약자용(p.9~10): 배점 = 부양가족수, **의왕시** 계속거주(5년↑3·3~5년 2·1~3년 1), 장애정도. 우선 = 주거약자 배점 → 의왕시 거주기간 → 추첨 / 일반 = 순위 → 주거약자 배점 → 추첨.
- 부양가족 범위(p.9): "① 신청자를 제외한 세대구성원(자격검증대상) 전원(태아 포함) ② 신청자 또는 배우자와 같은 등본에 있는 신청자의 형제·자매(미성년자 또는 60세 이상)" — LH14(p.8, ①~⑥ 6개 항목)보다 짧다.
- 최대 거주기간(p.25): 무자녀 10년, 자녀 1명 이상 14년(LH14의 "* 미성년자만 해당" 주석 없음).

## 7. 모호하거나 해석이 갈리는 지점 (MANUAL_REVIEW 후보)
1. **혼인 7년·6세 이하의 정확한 경계일이 원문에 없다**(p.1, p.5). 공식(공고일 −7년 / −7년+1일)으로 도출한 2019.9.29 / 2019.9.30에 걸리는 경계일 사례는 원문으로 확정할 수 없다. 같은 그룹 LH14·LH11이 이 공식과 일치하므로 근거는 강하지만, 이 공고에서는 해석값이다.
2. 한부모 ➀-㉰의 "(태아포함)" 위치가 "6세이하 자녀를 둔 한부모인 자(태아포함)"로 바뀌었다(LH14는 "6세이하(…출생, 태아포함) 자녀"). 의미 차이는 없어 보이지만 **불확실**하다.
3. 주거약자 요건이 신청자 본인 기준인지는 **불확실**하다(p.8 "주거약자의 요건을 갖춘 사람").
4. 우선공급 지역요건은 "의왕시에 거주하는 자"인데, 거주기간 하한이 없다. 거주 판정 기준은 "공고일 현재 계속하여 등재"(p.8)이다.
5. 소득 근거지 증빙 서류 안내(p.18)에서 LH14에 있던 "배우자가 소득이 있는 경우(맞벌이 신청자)"가 빠졌다. 맞벌이 판정 방법(p.7)은 같다.
