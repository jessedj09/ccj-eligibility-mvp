## 판정 틀
- 청년: SH 청년 매입임대(`sh.youth_rental`)의 청년 유형과 같은 조건·금액을 청년안심 문구로(대학생·취업준비생도 청년으로 신청).
- 신혼부부Ⅰ·Ⅱ: SH 신혼·신생아 매입임대Ⅰ·Ⅱ(`sh.newlywed`)와 같은 세부 자격·소득·자산 + 신청자 19~39세. 계층 이름은 `신혼부부Ⅰ`·
  `신혼부부Ⅱ`(괄호 이름은 흥신소 예비 판정이 한 계층으로 묶어 Ⅰ·Ⅱ가 섞이므로 새 이름으로 허용 목록에 더함).
- 모집 계층·금액·기준일은 추출기가 공고마다 원문에서 읽는다(`layers`·`money`·`dates`). 민간임대 청년안심주택은 판정하지 않는다
  (표지·수집 제목의 '민간임대').
