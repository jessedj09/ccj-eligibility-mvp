## 6. 순위·배점·우선공급 구조 (범위 밖 요약)
- 일반공급 순위(p.6, p.8): 1순위 = 본인 또는 배우자(예비신혼은 대표신청자 또는 예비배우자)의 거주지나 소득 근거지가 서울 또는 연접지역(의정부·남양주·구리·하남·성남·과천·안양·광명·부천·인천·김포·고양·양주) / 2순위 = 1순위 이외의 경기도 / 3순위 = 나머지.
- 우선공급(p.7): 1순위 영등포구 거주, 2순위 영등포구 외 서울 거주(신청자 본인 기준). 배점은 ① 영등포구 3년 이상 3점·3년 미만 1점, ② 청약 24회 이상 3점·6~23회 1점. 2순위는 ②만 적용.
- 경쟁 시(p.7): 우선 = 2세 미만 자녀 → 순위 → 배점 → 해당 지역 거주기간 → 추첨 / 일반 = 순위 → 추첨.
- 주거약자용(p.8~9): 배점 = 부양가족수(3인↑3·2인 2·1인 1), 서울 계속거주(5년↑3·3~5년 2·1~3년 1), 장애정도(중증 3·그 외 1). 우선 = 순위 → 주거약자 배점 → 거주기간 → 추첨, 일반 = 순위 → 주거약자 배점 → 추첨.
- 최대 거주기간(p.23): 무자녀 10년, 자녀(미성년) 1명 이상 14년.

## 7. 모호하거나 해석이 갈리는 지점 (MANUAL_REVIEW 후보)
1. **정정 내용을 알 수 없음**: 파일명만 "(정정)"이고 본문에는 정정 표시가 없다. 원본 PDF 또는 최초 공고와 대조해야 한다.
2. **"1인 가구 20% 가산"(p.4)과 결정표(p.5)의 불일치**: 가산 문구에는 1인 가구가 있는데, 신혼부부·한부모 결정표는 2인부터 시작한다. LH11(N1)도 문구가 같으며 N1은 1인을 NO_ROW로 처리했다. LH17에서는 이 문구가 "2인 가구 10% 가산"으로 바뀌었다(→ 행복주택 공통 문구를 그대로 가져온 흔적으로 보이지만 단정할 수는 없음).
3. "6세 이하 자녀"에서 태아를 인정하는 방법(임신진단서, p.15)과 "출산자녀 최대 2자녀"의 계산은 N1과 같은 쟁점이다.
4. 주거약자 요건이 신청자 본인 기준인지 세대원도 포함하는지: 원문은 "주거약자의 요건을 갖춘 사람"(p.7)이라고만 써서 세대원 포함 여부가 **불확실**하다.
5. 우선공급 거주지는 "공고일 현재 계속하여 등재"된 경우만 인정한다(p.7 예시: 중간에 전출하면 재전입일부터 산정).
6. 자동차가액: 총자산에는 모든 자동차를 합산하지만, 자동차 한도는 비영업용 승용차만 보고 2대 이상이면 가장 높은 가액을 기준으로 한다(p.21). car_value 입력값의 의미를 정해야 한다(N1과 같음).
