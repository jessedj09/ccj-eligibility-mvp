## 1. 공통 조건 패턴
### 든든전세 (LH04·LH05)
- 자격 = **무주택세대구성원**(세대 전원 무주택, 분양권 포함, 규칙 제53조 예외) ∧ **주민등록상 거주 모집권역 내 신청**(서울·인천·경기, "수도권 거주자만") ∧ 미성년(19세 미만) 불가(예외 3종) ∧ 외국인 불가 ∧ 불법양도·전대 적발 후 4년 미경과 세대원 없음 (LH04 p.1·3·4·10·11 / LH05 p.1·3·4·11·12).
- **소득·자산·자동차·청약통장·연령 상한·혼인 요건 모두 없음.** "중산층 가구에게 공급"(p.1)이라고만 함.
- 계층 없음. 예비신혼부부는 배점 적용 가구 설명에만 등장.
- 선정: 배점 총점(신생아 가구 2점 + 자녀수 1~3점) → 동점 추첨, 당첨자는 동·호 무작위 추첨.

### 청년매입임대 (LH06·LH07)
- 공통 = 공고일 현재 **본인 무주택**("부모가 주택을 소유한 경우에도 신청 가능") ∧ **미혼** ∧ 외국인 불가(재외국민 주민등록신고자 가능) (p.3, p.5, p.10).
- 계층(유형) = ① 청년 19~39세(생년월일 범위로 명시) / ② 대학생(입학·복학 예정 포함) / ③ 취업준비생(졸업·중퇴 후 2년 이내 미취업). **②③은 ①에 해당하지 않는 사람만** (p.3).
- 순위(소득·자산 트랙, 계층과 직교):
  - 1순위: 수급자 가구(생계·의료·주거급여) / 지원대상 한부모가족(본인) / 차상위계층 가구. 부모가 수급자·차상위면 동일 주민등록 등재 필요, 단 30세 미만이면 분리거주도 가능. **소득·자산 검증 없음**(p.3, p.11).
  - 2순위: **본인+부모** 월평균소득 ≤ 전년도 도시근로자 가구원수별 100%(1인 +20%p, 2인 +10%p) ∧ 본인+부모 자산 ≤ 국민임대 기준(총자산 34,500만, 자동차 4,542만).
  - 3순위: **본인** 월평균소득 ≤ 1인 100%(+20%p = 4,576,036원) ∧ 행복주택(청년) 자산기준(총자산 25,100만, 자동차 4,542만).
- 거주지 요건 없음, 청약통장은 배점만.

### 순위와 자격의 관계 ("자격 있음" = "하나 이상 순위 충족"인가?)
- p.3 입주자격 문장은 "소득 및 자산 기준을 충족하는"이라고만 하고, 그 기준은 **순위별 표로만** 정의된다(순위와 무관한 별도 상한 없음). 1순위는 소득·자산 대신 수급자 등 자격 확인이 그 자리를 대신한다. → 문면상 **자격 = 공통요건 ∧ 계층요건 ∧ (1순위 ∨ 2순위 ∨ 3순위)** 로 읽는 것이 맞다.
- 단, "**신청 후 순위 변경은 불가**하므로 신청 시 유의"(p.3, 2순위 신청 시 부모 인적사항 필수). 신청자가 고른 순위의 기준을 못 맞추면 하위 순위로 자동 이동하지 않는 것으로 읽힌다(부적격 처리 여부는 원문에 명시 없음 → **불확실**).
- 엔진 권고: (a) 순위별로 독립 판정해 "충족 순위 목록"을 반환하고, 하나라도 ELIGIBLE이면 ELIGIBLE. (b) 프로필에 "신청 순위"가 있으면 그 순위만으로 판정. (c) 모든 순위가 INELIGIBLE/NEEDS_INFO가 섞이면 NEEDS_INFO.
- 2순위 탈락자(부모 소득·자산 초과)도 3순위(본인 기준)로 적격일 수 있다 → 순위 간 소득 개념이 다르다는 점이 핵심.

### 함수·기준표
- 함수: 기존 `years_before`로 취업준비생 2년, 불법전대 4년 처리 가능. 생년월일 범위는 `birth_date` + 공고일에서 N년을 빼는 함수(`years_before` 재사용 가능)로 충분.
- 기준표: 기존 `income_standard` 재사용 가능. 2순위 비율은 결정표 {1인→120, 2인→110, 3인→100} 한 장으로 표현. 신규 기준표 불필요(배점용 50% 표는 범위 밖).

## 4. 🔴 항목 (새 구조 필요)
1. **순위(track) OR 구조** — 청년매입임대: 계층 아래 `tracks: [{rank:1, conditions}, {rank:2, …}, {rank:3, …}]`, 계층 판정 = 공통 조건 AND (트랙 중 하나 ELIGIBLE). 출력에 "충족 순위 목록"과 순위별 사유 필요. 현재 `any`로 한 조건식에 넣으면 논리는 되지만 순위별 출처 인용·NEEDS_INFO 사유·적격 순위 표시가 불가.
2. **같은 계층 안에서 소득 주체가 다른 두 기준**(본인+부모 vs 본인) — 필드 분리로 해결되지만, 2순위의 "가구원수"(본인+부모 인원?) 정의가 원문에 없음.
3. (범위 밖) **성별분리 주택** — 계층이 아니라 주택(모집단위) 속성에 따른 부적격.
- 든든전세에는 🔴 없음(계층 허용목록 + 필드 추가로 해결).
