# GROUP_3 요약 — LH 신혼희망타운 행복주택 (LH14 서울대방 정정 · LH17 의왕청계2 A1)

비교 기준: LH11(서울공릉 = 구현된 N1). 상세 내용은 `analysis/LH14.md`, `analysis/LH17.md`에 있다.

## 1. 결론
- 두 공고 모두 **N1과 같은 템플릿**이다. 계층은 신혼부부·예비신혼부부·한부모가족 3개이고, 공급은 일반/우선 × 일반형/주거약자형으로 나뉜다. 신청자격 요건 ➀-㉮㉯㉰·②~⑥의 구성도 같다.
- **소득·자산 수치와 결정표는 세 공고가 모두 같다**: 기존 2025년 도시근로자 표(3인 100% = 8,168,429), 7인 이상은 1인당 579,278원, 자산 345,000,000/379,000,000/413,000,000, 자동차 45,420,000/49,960,000/54,510,000, 비율 100~140%. 출산자녀 기준일은 '23.3.28, 최대 2자녀(LH14 p.4~6, LH17 p.4~6).
- 신청자격(필수요건)은 **N1 규칙을 거의 그대로 재사용할 수 있다**. 바꿀 것은 `announcement_date`와 컷오프 날짜뿐이다.

## 3. 공통 조건 패턴 (세 공고 공통)
- 무주택세대구성원(예비신혼은 혼인으로 구성될 세대 전원 무주택), 공고일 기준.
- 신혼부부: 혼인 중 + (혼인 7년 이내 또는 6세 이하 자녀, 태아 포함). 예비신혼은 ② 적용 없이 ⑥ 추가. 한부모는 6세 이하 자녀 + 같은 등본에 등재.
- 소득 100%(2인 110%), 맞벌이 120%(2인 130%), 출산자녀 1인 +10%·2인 이상 +20% → 결정표(가구원수 × 출생자녀수 × 맞벌이).
- 청약통장: 본인 또는 배우자 중 1인이 **입주 전까지**(한부모는 본인만) — BEFORE_MOVE_IN.
- 주거약자용: 일반공급 요건 + 65세 이상 또는 장애인·국가유공자 등 7개 유형 중 하나.
- 우선공급: 해당 시·구 거주 요건. 우선공급 자격이 안 되면 **일반공급으로 넘어가지 않고 탈락**(LH14 p.7, LH17 p.7).
- 최대 거주기간: 무자녀 10년, 자녀 1명 이상 14년.

## 5. 새로 필요한 필드/함수/기준표/구조
- **함수**: 새로 필요 없음. `marriage_cutoff`, `young_child_cutoff`, `child_bonus_count`로 충분하다(LH17은 fn 사용 필수).
- **기준표**: 새로 필요 없음. 2025 도시근로자 표와 N1 결정표를 그대로 쓴다.
- **🟡 프로필 필드**(N1에서도 모델링하지 않은 공통 항목이며, 이 그룹에서 새로 생긴 것은 아님):
  - 성년 여부와 예외(세대주인 미성년자 등). 예비신혼·한부모는 성년이 아니어도 가능
  - 국적·외국인등록 (외국인 신청 불가, 외국인 배우자는 등록을 마친 경우만)
  - 불법전대 적발 후 4년 이력
  - 주거약자 사유: 장애인 여부, 국가유공자·보훈보상·5·18·고엽제·준군경 상이등급 (65세는 age로 판정 가능)
- **🔴 구조**:
  1. **주택형 하위 공급유형(일반/주거약자)**: 같은 계층 안에서 요건이 추가되는데, 현재 layers는 4개 고정이다 → layer variant 또는 별도 layer가 필요.
  2. **공급트랙(우선/일반)별 자격**: 우선공급 자격이 안 되면 일반공급으로 넘어가지 않고 탈락한다. 지역 단위(구/시)와 순위 수가 공고마다 다르다(LH14 2단계, LH17 1단계). 판정 범위를 '일반공급 신청자격'으로 한정한다면 범위 밖으로 둘 수 있다.
