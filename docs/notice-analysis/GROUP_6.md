# GROUP_6 요약 — SH 미리내집 계열 (SH18, SH19, SH25, SH26)

## 0. 그룹 구성
같은 "미리내집" 이름 아래 **근거 제도가 다른 두 계열**이 섞여 있음.
| 계열 | 공고 | 공고일 | 근거 | 규모 |
|---|---|---|---|---|
| A. 일반주택형 미리내집 (매입임대 계열) | SH18 2026년 제1차 (신혼·신생아 매입임대주택Ⅱ) | 2026.8.14 | 「기존주택등 매입임대주택 업무처리지침」 (SH18 p28~30) | 128호 |
| | SH19 공공한옥 잔여세대 | 2026.8.24 | 같은 지침 준용 (SH19 p5, p26) | 4호(한옥) |
| B. 아파트형 = 장기전세주택2(미리내집) | SH25 제7차 | 2026.4.24 | 서울시 장기전세 (SH25 p5) | 신규 124 + 재공급 317 |
| | SH26 제8차 | 2026.8.21 | 같음 | 신규 293 + 재공급 203 |

A와 B의 연결점은 "신혼 출산가구 → 장기전세주택2 이주 혜택"뿐(SH18 p25, SH19 p24). **자격 규칙은 계열마다 완전히 다름.** 정정공고는 4건 모두 없음.

## 1. 공통 조건 패턴과 계열별 차이
| 항목 | A. 일반주택형(SH18·19) | B. 장기전세2(SH25·26) |
|---|---|---|
| 대상 계층 | 7개 유형: 신생아가구, 지원대상(보호대상) 한부모, 신혼부부, 예비신혼부부, 6세 이하 자녀 한부모, 6세 이하 자녀 혼인가구, 혼인가구 → 1~5순위 | 신혼부부(7년) + 예비신혼부부만 |

| 거주지 | **요건 없음** (SH19 가점 "서울시 미거주자 : 0점") | **공고일 현재 서울특별시 거주** (기간 요건 없음) |

**4건 공통 수치 기준**: 소득표 모든 셀이 2025년 도시근로자 표(3인 100% = 8,168,429)에 비율을 곱한 값과 일치 → 기존 기준표와 **같은 기준**(A는 "2026년도 공공주택 입주자 소득 및 자산기준"이라 부르고, B는 "전년도 도시근로자"라 부름). 자산 3단 구분(2023.3.28. 이후 출생 자녀 0/1/2명)은 기존 fn `child_bonus_count`의 0/1/2 출력과 정확히 대응.

## 2. 새로 필요한 것
### 프로필 필드
- 신청 주택 전용면적 구분(60㎡ 이하/초과) — B 소득기준 분기 (SH25 p13)
- 신청자·(예비)배우자 5년 무소유 여부 또는 최근 주택소유 종료일 — B ⑤ (SH25 p13)
- 수급자 여부, 차상위계층 여부, 한부모가족 증명서 대상 여부 — A 면제·유형 (SH18 p13)
- 외국인 여부(4건), 불법 양도·전대 적발 4년 이내 여부(4건) — 자기신고 → MANUAL_REVIEW
- 주거약자 요건: 장애인 등록, 국가유공자·보훈보상·5·18·고엽제 상이/장해등급 (SH26 p17~18)
- (선택) 주택도시기금 대출 상환 여부(A, 입주 전), 가구 세대 수(SH19 3대 대가족)

### 기준표 셀 (income_standard에 추가)
- B: 2인 100%, 2~5인 150%·180%·200% (기존 표에 없음)
- A: 3~5인 200%, 2인 210%(=200%+10%p). 2인 140%(=130%+10%p)는 기존 표에 있음. 임대조건 구간용 80%(2인 90%)는 판정에 불필요
- 6인 이상: A는 "5인 + 1인당 753,061/1,158,556원"(=579,278×비율) — 기존 7인 이상 가산값과 일치하나 서술 방식 다름. B는 6인 이상 기준 **미기재**

### 결정표
- 자산(A): bonus 0/1/2 → 36,200 / 39,600 / 43,100만원
- 자산·자동차(B): bonus 0/1/2 → 66,200 / 72,800 / 79,400만원, 4,542 / 4,996 / 5,451만원

### 함수 / 날짜 규칙 (중요)
- **SH는 기간 컷오프를 "공고일 N년 전 다음날"로 씀**: 혼인 7년 SH25 2019.4.25(공고 4.24), SH26 2019.8.22(8.21), SH18 '19.08.15(8.14), SH19 '19.8.25(8.24); 신생아 2년 SH18 '24.08.15, SH19 '24.8.25; 5년 무소유 2021.4.25/2021.8.22; 미성년 2007.4.25/2007.8.22.
- 기존 `marriage_cutoff(공고일)` = 공고일 7년 전 **당일**(LH N1 원문 기준) → SH에 쓰면 하루 이른 날짜가 나와 경계일 혼인자를 잘못 ELIGIBLE 처리. → **원문 date 리터럴을 쓰거나, 발행기관별 함수(7년 전 + 1일) 추가**.
- `young_child_cutoff`(7년 전 + 1일)는 SH18 '19.08.15와 일치 ✅. 미성년 기준(19년 전 + 1일)도 `bonus_child_count`의 adult_line 로직과 일치 ✅.
- 신생아 2년(2년 전 + 1일)용 함수 없음 → 리터럴로 충분.

## 3. 🔴 새 구조가 필요한 항목
1. **layer 확장**(A): 신생아가구, 혼인가구(6세 이하 자녀), 혼인가구(기타)는 기존 4개 layer(대학생/청년/신혼부부/한부모)에 없음 → 로더 허용 목록 확장 필요. 신혼·예비신혼 → `신혼부부`, 한부모 2종 → `한부모`로 부분 매핑만 가능.
2. **신청 주택(면적·유형)에 따라 갈리는 요건**(B): 60㎡ 이하/초과 소득기준. 면적을 입력받으면 🟡로 처리 가능하지만, 공고 단위로 한 번에 판정하려면 면적 구분별 결과를 따로 내는 구조가 필요.
3. **주거약자형 주택**(SH26): 계층이 아니라 공급 주택 유형에 붙는 추가 자격(신청자 본인 ①~⑦ 중 1개) → 주택유형 차원 필요.
4. (범위 밖) A의 1~5순위, SH19의 주택별 3대 대가족 우선, B의 40% 소득 우선배정, A의 임대조건 구간(80% 이하 → 시세 60%) 출력.
5. (MANUAL_REVIEW) SH19 대가족 2순위의 "입주 시 구성될 세대" 기준 소득·자산 심사 — 현재 가구 프로필 모델 밖.

## 4. 그대로 되는 것 (✅)
서울 거주(B, residence_region), 무주택세대구성원, 예비신혼 입주 전 혼인(BEFORE_MOVE_IN), 맞벌이(dual_income: 근로·사업소득 둘 다), 6세 이하 자녀(young_child_cutoff), 자산·자동차(child_bonus_count + 새 결정표), 가구원수(태아 포함 입력 안내), 미성년자 신청 불가(age), 대학생·청년 → NOT_OFFERED.

## 5. 회차·자매 공고 간 정확한 차이

- SH26에만: 주택관리번호 85㎡ 이하/초과 2개(2026000411/415), 85㎡ 초과 주택(목동센트럴푸르지오 110㎡ 2호), **주거약자형**(마곡엠밸리17단지 59㎡ 6호 + 추가자격 p17~18), **감점 예외**(가구원수 변동 이주, 2009.11.29. 이전 계약자 비대상, p20), 별표2 토지가액·제외 부동산, 별표1 검색대상에 예비신혼 명시, 50% 초과 할증 재계약 1회 후 추가 재계약 불가 명시, "공공주택"→"공공임대주택".
- SH26에서 빠진 것: 우선배정 [60㎡ 초과] 120%/180% 표(신규공급 전부 59㎡ 이하), p15 "분양권·소형저가주택 주택소유 간주" 안내 문단, 단지별 개별 유의사항, 누수·결로 인원변동·발표 연기 문구.

### SH18(제1차) ↔ SH19(공공한옥): 자격 체계·소득·자산 수치 동일
- 날짜: 공고일 8.14→8.24, 신생아 '24.08.15→'24.8.25, 신혼 '19.08.15→'19.8.25, 65세 1961.08.14→1961.8.24.

- 한부모 명칭: "지원대상"·여성가족부장관 / "보호대상"·성평등가족부장관.
- SH19에만: 2개 한옥 3대 이상 대가족 우선, 12배수(SH18 3·5·6배수), 가점 "서울시 미거주자 0점", 배우자 주민등록말소·거주불명 시 신청불가, 한옥 유의사항.

## 6. MANUAL_REVIEW 후보 (대표)
- 혼인·신생아 컷오프 +1일 관행(4건) — 리터럴 사용 시 해소.
- B: 6인 이상 소득기준 미기재, 청약통장 필수 여부 불확실, 소득·자산을 사회보장정보시스템 조회시점 자료로 판단(SH25 p5, p18), 주택 보유 시 소형·20㎡ 이하 예외(SH25 p15 vs p39), 주거약자 "신청자 본인 기준"(SH26 p11).
- A: 면제는 증명서 제출 시만 적용, 6인 이상 가산 문구 불명확, 세대분리 한부모·예비신혼은 세대구성확인서상 세대 기준.

## 7. 텍스트 추출 문제
- 텍스트 없는 쪽: SH18 p2, p4 (p50, p51은 쪽 머리말만 — 목차상 별첨7(p49)과 주택목록(p52) 사이, 내용 불명); SH19 p35(뒷표지), p1 표지는 제목만; SH25·SH26 p2, p4, p47.
- **판정에 필요한 표(소득·자산 기준표, 신청자격, 배점표)는 4건 모두 텍스트로 온전히 추출됨** — 누락된 핵심 표 없음. 빈 쪽은 목차에 대응하는 절이 없어 간지·이미지로 보임(불확실하나 목차 대비 빠진 절은 없음).
- 표 깨짐: 공급현황 표의 셀 줄바꿈(예: SH25 p8 "난방 '26. 12.50 일반 6 …"처럼 두 행이 붙음), SH18 p13 "17,604,40418,653,970" 숫자 붙음(4인 17,604,404 / 5인 18,653,970으로 분리 확인), SH18 숫자 사이 공백("7 ,041,762"). 수치는 비율 재계산으로 모두 검증함.
- SH19는 도구가 "NUL bytes" 경고를 냈으나 실제 NUL 문자는 0개(특수 글머리 문자 "Ÿ" 등 때문으로 보임). 내용 판독에는 문제 없음.
