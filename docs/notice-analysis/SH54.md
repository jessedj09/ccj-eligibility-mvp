# SH54 — SH 2025년 영구임대주택 예비입주자 모집 (SH 영구임대)

G5(2026-11-03) SH 영구임대 판정 틀(`sh.permanent_rental`)의 첫 공고(N54). 공고 1건으로 만든 틀이다 — 다음 공고(매년 11월 무렵)가
다른 기준 연도면 소득 기준표(연도 확인)와 총자산·자동차 한도(리터럴 문구 확인)가 보류로 드러나고, 운영자가 새 기준표를 승인하면
판정한다.

| 항목 | 내용 |
|---|---|
| 모집공고일 | 2025.11.13. |
| 접수 | 2025.11.24.~11.28. 거주지 동 주민센터 현장 접수(원문에 시각 없음) |
| 공통 | 공고일 현재 서울 거주 성년 무주택세대구성원, 외국인 불가, 금융정보 제공 동의서 필수 |
| 1순위(가~자) | 가 생계·의료급여 / 나 국가유공자 등(70%) / 다 일본군위안부 피해자(판정에서 묻지 않음) / 라 지원대상 한부모 / 마 북한이탈주민(70%) / 바 장애인(70%) / 사 65세 이상 직계존속 부양자(소득인정액 — 확인 필요) / 아 아동복지시설 퇴소자(70%) / 자 65세 이상 수급권자·차상위 |
| 소득 | 70%(1인 90%·2인 80%, 출생자녀 1명 +10%p·2명 이상 +20%p) — '2025년도' 표 1~8인(p.10, LH 영구임대 표와 금액이 다름) |
| 자산 | 총자산 23,700만·자동차 4,563만(출생자녀 1명 26,100만·5,020만, 2명 이상 28,500만·5,476만) |

2순위는 없다. 선정은 배점(서울 거주기간·연령·세대원수 등) 순이라 판정하지 않는다. 등록: `tools/gen_c6_public.py` PLAN N54.
소득 기준표: `rules/reference/income_standard_sh_permanent.json`.
