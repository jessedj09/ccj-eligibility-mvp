# 회원 기능 운영 설정 (2026-11-07)

회원가입·로그인·내 조건 저장(`src/accounts.py`)을 운영에서 켜는 데 필요한 값과 절차. 비밀 값은 저장소·채팅·문서에 쓰지 않고 Render 대시보드
(`ccj-api` → Environment)에만 넣는다. `render.yaml`에는 값 없이 이름만 있다(`sync: false`).

## 1. 내 조건 암호화 키 — `CCJ_PROFILE_KEY`

**역할:** 회원이 저장한 조건(생년월일·소득·자산·거주지 등)을 DB에 넣기 전에 AES-GCM으로 잠그는 키. DB에는 암호문만 들어가 DB가 유출돼도
키 없이는 읽을 수 없다. **키가 없으면** 가입·로그인은 되지만 내 조건 저장이 "아직 설정되지 않았습니다"(503)로 멈춘다 — 평문으로 저장하는 일은 없다.

**만드는 명령(한 번만, 32바이트 무작위):**

```
python -c "import os,base64;print(base64.urlsafe_b64encode(os.urandom(32)).decode())"
```

출력된 한 줄을 Render `CCJ_PROFILE_KEY` 값으로 붙여 넣는다.

**주의**
- **분실하면 복구할 수 없다.** 이미 저장된 조건을 아무도 열 수 없다. 만들자마자 비밀번호 관리자 등 안전한 곳에 한 벌 따로 보관한다.
- **바꾸면 안 된다.** 쓰기 시작한 뒤 키를 바꾸면 기존 조건이 모두 열리지 않는다(재암호화 기능 없음). 저장한 조건이 없는 지금이 정하기 가장 부담이 적다.
- 채팅·문서·저장소·로그에 붙여 넣지 않는다. 비밀번호는 이 키와 무관하다(scrypt 해시로 따로 저장).
- 언제: 메일 발송·도메인을 준비해 베타를 열기 직전에 같이 해도 된다(지금 서둘러 만들 필요는 없다 — 키가 없는 동안은 조건 저장이 닫혀 있다).

## 2. 메일 발송(인증 코드) — 베타 전

| 환경 변수 | 값 |
|---|---|
| `CCJ_MAIL_BACKEND` | `resend` — 비우면 가입·비밀번호 재설정이 503 |
| `RESEND_API_KEY` | Resend 계정의 API 키 |
| `CCJ_MAIL_FROM` | 보내는 주소(도메인 인증 뒤 — 인증 전에는 Resend 계정 본인 주소로만 보내진다) |

도메인을 사서 Resend에서 인증한 뒤 `CCJ_MAIL_FROM`을 그 도메인 주소로 바꾼다. 처리방침 3절의 "메일 발송 대행" 업체 칸도 이때 확정해 적는다.

## 3. 1년 미접속 계정 파기(선택)

처리방침 2절은 "1년 동안 로그인하지 않은 계정을 지운다"고 적었다. 지키려면 둘 중 하나:
- GitHub 저장소 Secrets에 `PROD_DATABASE_URL`을 넣으면 `.github/workflows/purge-accounts.yml`이 매주 월요일 03:00(KST) 돌아간다(비밀값이 없으면 아무것도 안 한다).
- 운영자 PC에서 가끔 `python tools/purge_accounts.py`(`--dry-run`으로 지울 수만 먼저 확인).

둘 다 하지 않기로 하면 처리방침 2절 문구를 먼저 고친다(약속과 실제를 맞춘다).
