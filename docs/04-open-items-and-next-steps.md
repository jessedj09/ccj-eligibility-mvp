  "손으로 원문을 재확인한 사람(Claude)이 손으로 판정 로직을 고친 것"이라 03번 문서의
  근본적 한계(정답지와 코드가 같은 사람 손에서 나와 같은 오해를 공유할 수 있음)에서
  자유롭지 않다.
- 아직 UI에서 실제 브라우저 클릭 테스트(골든 패스 + 엣지 케이스)는 정적 코드 리뷰 +
  로컬 서버 기동 확인까지만 했고, 위젯 상호작용까지 눈으로 확인하지는 못했다.

✅ **MVP0.2 — 신뢰성(A단계) 1차** — `MANUAL_REVIEW` 상태 구현, N3 자녀 컷오프 1일 오류 수정,

## 사람 검증 없이 진행 가능하다고 합의했던 순서

1. ✅ 경계값(boundary) 자동 테스트 — 완료 (`tests/test_boundaries.py`)
2. LH 공식 자가진단 도구와 대조 (외부 독립 검증) — **미착수**, 접근 가능 여부(로그인/
   공인인증 필요 여부)부터 확인 필요
3. ✅ 미구현 영역 채우기(자녀가산, 우선공급 배점, 재학요건, 연령/사회초년생, 혼인기간/
   자녀요건) — MVP0.1에서 완료
4. 이상치(adversarial) 입력 테스트 — **부분 완료**. `validate_profile()`과
   `tests/test_mvp0_1_fixes.py`의 일부 테스트(음수 소득, 미래 날짜 등)로 커버했으나,
   코덱스가 요청한 전체 카탈로그(자료형 오류, 모순 입력 조합 등)를 빠짐없이 다루지는
   못했다 — 계속 확장 필요.
5. ✅ 자동 회귀테스트로 전환 — 완료 (pytest 172개)
